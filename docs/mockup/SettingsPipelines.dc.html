Pipeline'lar

3 dosya

Araçları zincirle: her adımın çıktısı sonrakinin girişi olur. Pipeline'lar palette'te araç gibi listelenir ve CLI'dan çalışır: kotilo kit jwt-scopes < in.txt

  • jwt-scopes Base64 decode→ JSON $.scopes→ Case UPPER
  • csv-to-md Satır işlemleri tekilleştir→ CSV → Markdown
  • gz-payload Base64 decode→ gzip→ JSON
    2. adım: "gzip" adlı araç yüklü değil. Palette'te gösterilmiyor.

Dosya biçimi

~/.config/kotilo/kit/pipelines/jwt-scopes.toml 
name = "jwt-scopes"
palette = true

[[steps]]
tool = "base64"
opts = { mode = "decode", urlSafe = true }

[[steps]]
tool = "json"
opts = { query = "$.scopes[*]" }
